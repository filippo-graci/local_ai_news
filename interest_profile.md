# Interest profile

> **Blank checklist for a custom profile.** Fill it in with the reader's own
> preferences, then rewrite `prompts/interest_filter.txt` to match (see README,
> "Personalising"). Until that prompt is rewritten, the pipeline keeps using the
> premade preset in `premade_interest_profile.md`.

Fill each `[ ]` with one letter:

- `y` = always interested
- `m` = only when it's major (national/international consequences)
- `n` = never

Leave blank if you have no opinion (treated as `m`). Add free-text notes anywhere.
